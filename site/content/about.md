안녕하세요, 전북대학교 컴퓨터공학부 안진성입니다.
사람들이 실제로 쓰는 웹 서비스를 프론트엔드부터 서버까지 직접 만들어 보는 것을 좋아합니다.

## 관심 분야: 웹 서비스 개발

부모님이 하시는 일에 도움이 될 서비스를 직접 구현해 보고 싶어서 웹 서비스 개발에 관심을 갖게 되었습니다.
이 관심은 구매자의 주문을 받고 판매자가 입금 확인부터 배송 완료까지 관리하는
사과 주문·배송 서비스 [사과랑]({{< ref "projects/apple" >}})으로 이어졌습니다.

## 학습 목표와 다음 행동

**목표**: 사과랑을 실제로 배포해서 판매자와 구매자가 개발용 로그인 없이 사용할 수 있는 상태로 만드는 것입니다.

이를 위해 다음 순서로 진행할 계획입니다.

1. 카카오 개발자 콘솔에 앱을 등록하고, 개발용 로그인 대신 카카오 로그인으로 접속을 확인합니다.
2. 데이터베이스를 PostgreSQL로 옮기고 API 서버와 구매자·판매자 웹 앱을 각각 배포합니다.
3. 주문 상태를 15~20초마다 다시 불러오는 폴링 방식을 Firebase 푸시 알림으로 바꿉니다.

## 사용하는 기술과 적용 사례

### 프론트엔드와 백엔드 연동 (React · Express)

사과랑에서 React로 만든 구매자 앱과 판매자 앱이 하나의 Express API 서버를 함께 사용합니다.

- 두 앱의 모든 HTTP 요청이 `shared/api/client.js` 한 곳을 지나가게 해서,
  로그인 토큰 첨부와 서버 오류 처리를 한 번만 구현했습니다.
- 개발 중에는 Vite 프록시가 `/api` 요청을 서버(4000번 포트)로 넘기고,
  배포 환경처럼 프론트와 서버의 주소가 다를 때는 `VITE_API_BASE_URL`로 서버 주소를 지정하도록 했습니다.
